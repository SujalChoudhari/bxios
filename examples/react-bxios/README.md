# React bxios example

This private workspace package demonstrates consuming `@bxios/bxios` from React alongside a small `@bxios/server` streaming backend. It is TypeScript-compiled and does not supply a bundled application shell.

## Tracked contents

- `package.json` — workspace scripts and React/client/server dependencies.
- `tsconfig.json` — TypeScript configuration.
- `src/` — the component and matching demonstration server.

## Navigation

See [`src/README.md`](src/README.md) for both source files. Build or type-check with `pnpm --filter @bxios/example-react build` or `pnpm --filter @bxios/example-react test`. The repository [`README.md`](../../README.md) gives context; library behavior is in [`packages/bxios/README.md`](../../packages/bxios/README.md) and [`packages/server/README.md`](../../packages/server/README.md).
